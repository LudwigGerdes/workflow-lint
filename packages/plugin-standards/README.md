# workflow-lint-plugin-standards

workflow-lint's opinionated rule set: reliability, naming, structure, hygiene, data and layout.

Part of [workflow-lint](https://github.com/LudwigGerdes/workflow-lint), a linter and formatter for workflow JSON. n8n is the first supported platform. This is a private workspace package: it is not published on its own, and is bundled into the one published package, `workflow-lint`.
