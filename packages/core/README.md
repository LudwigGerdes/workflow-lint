# workflow-lint-core

The rule engine behind workflow-lint: workflow graph, rule runner, autofix, source maps, configuration, and the rule tester.

Part of [workflow-lint](https://github.com/LudwigGerdes/workflow-lint), a linter and formatter for workflow JSON. n8n is the first supported platform. This is a private workspace package: it is not published on its own, and is bundled into the one published package, `workflow-lint` (as `workflow-lint/core` and `workflow-lint/rule-tester`).
