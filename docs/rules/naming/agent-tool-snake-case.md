# naming/agent-tool-snake-case

Tool names are passed to the model as identifiers, so they must be snake_case.

|  |  |
|---|---|
| Department | `naming` |
| Class | `quality` |
| Recommended | `warn` |
| Fixable | `params` (safe) |

## Messages

| Message ID | Template |
|---|---|
| `snakeCase` | Tool name "{{name}}" should be snake_case, such as "{{suggestion}}". |
