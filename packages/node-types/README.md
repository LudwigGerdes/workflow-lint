# workflow-lint-node-types

Node description bundles used by workflow-lint to validate nodes offline. The bundles are derived from n8n packages; see THIRD_PARTY_NOTICES.md.

Part of [workflow-lint](https://github.com/LudwigGerdes/workflow-lint), a linter and formatter for workflow JSON. n8n is the first supported platform. This is a private workspace package: it is not published on its own, and is bundled into the one published package, `workflow-lint` (its `versions/` data ships there too).
