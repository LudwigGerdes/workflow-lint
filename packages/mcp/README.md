# workflow-lint-mcp

The Model Context Protocol server for workflow-lint, so an agent can lint and fix workflow JSON.

Part of [workflow-lint](https://github.com/LudwigGerdes/workflow-lint), a linter and formatter for workflow JSON. n8n is the first supported platform. This is a private workspace package: it is not published on its own, and is bundled into the one published package, `workflow-lint` (as the `workflow-lint-mcp` bin).
